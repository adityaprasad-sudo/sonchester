# ♟️ Sonchester

**Sonchester** is not your average chess game.

Forget the classic **White vs Black** pieces. In Sonchester, the battlefield is completely reimagined:

* 🐐 **Anson "The GOAT"** commands one side.
* 🌶️ **The Chilies** fight on the other.

This is a **fully custom-made chess game** that throws traditional chess rules out the window and replaces them with unique mechanics, unexpected gameplay, and custom logic.

## ✨ Features

* 🎮 Completely custom chess experience
* 🐐 Play as **Anson "The GOAT"**
* 🌶️ Battle against **The Chilies**
* ⚡ Unique game mechanics and rules
* 🎨 Custom-designed board and pieces
* 🚀 Built from scratch with custom logic

## 📖 About the Game

Sonchester isn't meant to be a standard chess simulator.

Every piece, movement, and interaction has been designed to create a fresh experience. If you're expecting traditional chess, you're in for a surprise.

Some mechanics may look familiar, but many have been redesigned to make every match feel different.
